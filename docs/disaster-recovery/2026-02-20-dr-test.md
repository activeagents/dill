## Issues Encountered

### 1. GCP Authentication Expired
- **Issue**: OAuth token expired with "invalid_grant" error
- **Resolution**: Re-authenticated with `gcloud auth application-default login`

### 2. Dockerfile Platform Variable
- **Issue**: `FROM --platform=$TARGETPLATFORM` failed in Cloud Build (TARGETPLATFORM not set)
- **Resolution**: Changed to `FROM base as build` (Cloud Build uses linux/amd64 by default)

### 3. Cloud Build Permissions
- **Issue**: Compute service account lacked permissions for:
  - `storage.objects.get` - Reading source tarball
  - `artifactregistry.repositories.uploadArtifacts` - Pushing Docker images
- **Resolution**: Added IAM roles:
  - `roles/storage.objectViewer`
  - `roles/artifactregistry.writer`
